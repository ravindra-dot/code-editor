# Security policy

CodeSphere executes submitted Python, C, and C++ code in restricted Docker containers. The container limits reduce risk, but the host running Docker still needs careful maintenance.

## Reporting a vulnerability

Please avoid posting exploit details in a public issue. Use the repository's **Security → Report a vulnerability** option on GitHub if it is available. If it is not available, contact the maintainer privately through the contact details on their [GitHub profile](https://github.com/ravindra-dot).

Include a concise description, steps to reproduce, the affected component, and the potential impact. Please allow time for a fix before publishing details.

## Supported version

Security fixes are made on the current `main` branch. There are no maintained release branches.
